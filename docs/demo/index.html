Elixir Order Desk: live replay

A recorded run of the real pipeline, so you can see it work without a key or any setup. Each message went through Order Desk exactly as it would in production: WhatsApp (through the repo's local simulator), Meta's models through the Meta Model API, and orders and goods receipts booked in the Odoo test ERP from erps/. Only the replay timing is added; every message, step, model call and cost below was recorded.
