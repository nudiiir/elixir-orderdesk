# What Muse Spark identified: mobile phones and accessories / consumer electronics

Names are brand + type + model code + key specs, order varies. Phones/tablets/laptops are told apart by RAM/storage written as 12/256GB, 12+12/256GB, 8+8/256GB or 32/256SSD and by storage 64GB/128GB/1TB. Chargers/cables are told apart by connector type-c/micro/lighting-ios/jack, power 25W/60W/100W, voltage/current 19V/3.42A and length 1.5M/2M/20M, plus codes like BW29, YSW13, KSC-813. Original vs copy/org/orig and with box vs sans boite also separate otherwise identical lines.
